- Push the current branch, then run:
    `git push -u origin HEAD`.
- Do not switch branch to push code.
- Push only what is already committed. Do not stage or commit anything.
- Never force push. If the push is rejected, report the reason and stop.
- Prompt the user if a force push is needed (heads have diverged). After confirmation force push
  with leash
