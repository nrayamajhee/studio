# Set the tempo

**Tempo** (the metronome pad, `M`) shows the beats per minute. Turn the green knob or press ← →, drag the number, or click it to type one. Press ↓ to **tap** the tempo in on the keys. **Shift + Tempo** starts or stops the click.
